## 🌟 प्रोजेक्ट परिचय (Overview)

**ग्राम सचिवालय दसदोई** उत्तर प्रदेश सरकार के पंचायती राज विभाग के अंतर्गत एक डिजिटल रूप से सशक्त, पारदर्शी एवं आधुनिक ग्राम सचिवालय की परिकल्पना को साकार करने वाला एक इंटरएक्टिव 3D वेब अनुभव है। 

यह प्रोजेक्ट पारंपरिक सरकारी पोर्टलों एवं स्टैटिक कार्ड-आधारित लेआउट से परे, **Awwwards-स्तरीय सिनेमैटिक डिजिटल आर्किटेक्चर** प्रस्तुत करता है:
- **Three.js WebGL 3D इंजन**: वास्तविक भवन और कक्षीय तस्वीरों के साथ 3D डेप्थ व कैमरा पारगमन।
- **सिनेमैटिक साई-फाई टर्मिनल टाइपिंग इंजन**: `Intl.Segmenter` द्वारा देवनागरी अक्षरों को बिना मात्रा तोड़े टाइप करने की अनूठी तकनीक।
- **सिंथेसाइज़र डिजिटल कीस्ट्रोक ऑडियो (Web Audio API)**: जीवंत कीस्ट्रोक साउंड एवं कन्फर्मेशन बीप।
- **मोबाइल एवं टच अनुकूलित**: स्वाइपेबल रूम स्टेपर, बॉटम-शीट ड्रॉर एवं टच-फ्रेंडली 3D हॉटस्पॉट्स।

## ⚡ मुख्य तकनीकी विशेषताएं (Key Technical Features)

1. **`Intl.Segmenter` आधारित देवनागरी ग्रैफीम क्लस्टरिंग**:
   - पारंपरिक जावास्क्रिप्ट `split('')` हिंदी की संयुक्त मात्राओं और हलंत (जैसे `ग` + `्` + `र` = `ग्र`) को तोड़ देता है।
   - इस प्रोजेक्ट में `new Intl.Segmenter('hi', { granularity: 'grapheme' })` का उपयोग कर प्रत्येक देवनागरी अक्षर को उसकी संपूर्ण मात्रा व संयुक्त रूप के साथ अक्षुण्ण रखा गया है।

2. **Web Audio API मैकेनिकल साउंड इंजन**:
   - बिना किसी बाहरी भारी MP3 ऑडियो फ़ाइलों के, ब्राउज़र के नेटिव ऑडियो ऑसिलेटर द्वारा 1800Hz - 2150Hz पिच जिटर के साथ यथार्थवादी डिजिटल कीस्ट्रोक साउंड।
   - यूजर जेस्चर के बाद स्वतः अनलॉक एवं टॉपबार में वन-टैप म्यूट/अनम्यूट टॉगल।

3. **Lenis + GSAP ScrollTrigger स्मूथ स्क्रॉल**:
   - 60 FPS स्मूथ स्क्रॉलिंग, जो स्क्रॉल की गति के अनुसार 3D कैमरे की स्थिति (`Vector3`) को सटीक रूप से रोटेट और ट्रांसलेट करती है।

4. **100% रिस्पॉन्सिव मोबाइल आर्किटेक्चर**:
   - iOS और Android के लिए सुरक्षित एरिया इनसेट सपोर्ट (`viewport-fit=cover`)।
   - मोबाइल स्क्रीन के लिए टच-स्वाइप स्टेपर रिबन।
   - बॉटम-शीट ड्रॉर मॉडल्स एवं 16px ज़ूम-फ्री फॉर्म इनपुट्स।

## 🚀 स्थानीय स्तर पर चलाएं (How to Run Locally)

किसी भी लोकल वेब सर्वर (Python, Node, Live Server) द्वारा आसानी से चलाएं:

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/ASDFRFFD/gram-sachivalaya-dasdoi.git
cd gram-sachivalaya-dasdoi

# पायथन द्वारा लोकल सर्वर शुरू करें
python -m http.server 5500
```

इसके बाद ब्राउज़र में खोलें:
👉 `http://localhost:5500`
